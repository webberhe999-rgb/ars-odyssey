# Ars Nouveau: Odyssey / 新生魔艺：奥德赛

Ars Nouveau: Odyssey is an Ars Nouveau addon focused on glyph indexing, spell-use discovery, player knowledge, Resonance Nexus systems, and magical progression.

This project is based on the official [Ars Nouveau Example Addon](https://github.com/baileyholl/Ars-Nouveau-Example-Addon) template.

## Development

This project targets Minecraft 1.21.1, NeoForge, and Ars Nouveau.

Useful commands:

```powershell
.\gradlew.bat compileJava
.\gradlew.bat runClient
.\gradlew.bat runServer
```
